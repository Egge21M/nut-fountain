# Canonical protocol documentation

The [version-1 protocol specification](../packages/nut-fountain/docs/protocol.md) is the single canonical definition of the binary fountain wire format and interoperability requirements. This file is a navigation pointer, not a separate specification.

The [implementation guide](../packages/nut-fountain/docs/implementation.md) describes the TypeScript implementation, worked decoding example, APIs, Cashu helpers, and inbound UR support. Those implementation details do not add protocol requirements.
